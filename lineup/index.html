怎麼用

  1. 上面選這一輪：前排的舉球員站在 4、3 還是 2 號位。
  2. 按「播放」看一整波：接發球 → 攻擊 → 回防 → 攔網、防守 → 第二波攻擊。可以暫停、上一步、下一步，「慢速」會放慢。
  3. 在第 1～2 步可以直接拖白色的球換落點、拖對方發球員換發球位置，看看換誰接。
  4. 按「換你擺」：自己把人拖到接發球位置，按「檢查」看有沒有站錯；後面到了防守也會停下來讓你擺。

加到手機主畫面

  1. iPhone：用 Safari 打開 → 分享 → 加入主畫面
  2. Android：用 Chrome 打開 → 右上角 ⋮ → 加到主畫面
  3. 從 LINE 打開的：先點右上角 ⋯ → 用瀏覽器開啟
