練習：對方怎麼守

對方防守
對方攔網

我們攻擊時，對方都照這樣守。對方打過來的球是隨機的。

怎麼用

  1. 首頁或右上角選教學或練習，上面再選這一輪：前排的舉球員站在 4、3 還是 2 號位。
  2. 教學：按「下一步」一步一步看大家怎麼站、怎麼跑（按「自動播」會自己往下走，字多的地方停久一點）。看完按「換你試」，點你打的位置，同一球再跑一次，每到你要動的地方會停下來，把「我」拖到你覺得要去的地方，按「確定」看對不對。
  3. 要點場上的時候，場上會框起來、有手指在點：發球落點、我們要打哪裡、對方打哪裡。上面可以換一傳好壞、舉長攻或二號、對方怎麼攻擊。
  4. 練習：先設定對方怎麼守、有幾個人攔網，按「開始」就像比賽一樣打一球，結果會隨機。站位可以先拖人調整；要舉給誰、接噴要修去哪這些地方，會停下來讓你選。
  5. 播放時場上不放字，想知道為什麼，按「為什麼？」。防守時按「誰守哪裡」，看每個人負責哪裡：顏色深的一定是她接，淡的是別人也可以接，紅色是空檔。
  6. 練習的比分只是好玩，這裡不會換輪；要換輪按上面。

加到手機主畫面

  1. iPhone：用 Safari 打開 → 分享 → 加入主畫面
  2. Android：用 Chrome 打開 → 右上角 ⋮ → 加到主畫面
  3. 從 LINE 打開的：先點右上角 ⋯ → 用瀏覽器開啟

跑法照教練的說法畫；跟教練現場講的不一樣時，以教練為準。
