怎麼用

  1. 上面選這一輪：前排的舉球員站在 4、3 還是 2 號位。
  2. 按「播放」看一整波：接發球 → 攻擊 → 回防 → 攔網、防守 → 第二波攻擊。可以暫停、上一步、下一步，「慢速」會放慢。
  3. 先拖上面的紅色三角形選對方發球員站哪裡，大家的接發球位置會跟著微調；站好後點我們的場上選發球落點，看誰去接。
  4. 對方要攻擊時會停下來：點我們場上任何一個地方，或按「直線」「斜線」「吊球」這些路線，看誰接、誰補位。看完按「再一球」換別的地方。上面可以切換誰攔網。
  5. 按「換你擺」：自己把人拖到接發球位置，按「檢查」看有沒有站錯；後面到了防守也會停下來讓你擺。

加到手機主畫面

  1. iPhone：用 Safari 打開 → 分享 → 加入主畫面
  2. Android：用 Chrome 打開 → 右上角 ⋮ → 加到主畫面
  3. 從 LINE 打開的：先點右上角 ⋯ → 用瀏覽器開啟

跑法照教練的說法畫；跟教練現場講的不一樣時，以教練為準。
